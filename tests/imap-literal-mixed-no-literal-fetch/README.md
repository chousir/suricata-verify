# Description

Tests a FETCH response batch containing a literal-less line before a
literal-bearing one: `* 1 FETCH (FLAGS (\Seen))\r\n` followed by
`* 2 FETCH (RFC822 {9}...)`.

This exercises `find_next_literal`'s skip-then-find loop: it must walk
past the FLAGS-only FETCH line (which matches the FETCH header but
declares no literal) without mistaking it for the literal announcement,
and correctly consume the second FETCH's literal. Exactly one
`fileinfo` event (`size: 9`) is expected.

# PCAP

Synthetic pcap generated by `gen_pcap.py` (scapy), modeled on
`imap-literal-basic`. Regenerate with `python3 gen_pcap.py`.
